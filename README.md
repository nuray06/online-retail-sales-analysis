# Online Retail: Sales Performance & Customer Behavior Analysis

## 1. Project Overview
Интернет-магазин располагает историей транзакций покупателей, однако для принятия бизнес-решений необходимо понять, как меняются продажи, какие товары пользуются наибольшим спросом и какие клиенты приносят наибольшую выручку.
Без анализа этих данных сложно определить наиболее важные направления продаж и выявить возможности для улучшения бизнеса.

**Цель проекта** - проанализировать историю транзакций интернет-магазина, выявить закономерности в продажах и поведении покупателей, а также сформулировать рекомендации на основе полученных результатов.

### Вопросы
1. **Sales Trends:** Как изменяются продажи по месяцам? В какие периоды наблюдается рост или снижение?
2. **Country Analysis:** Какие страны обеспечивают наибольшую сумму продаж?
3. **Product Analysis:** Какие товары наиболее популярны по количеству продаж и какие приносят больше всего выручки?
4. **Customer Behavior:** Какие клиенты совершают покупки чаще всего и тратят больше всего денег?
5. **Returns Analysis:** Как возвраты и отмены влияют на финансовые показатели магазина?

### Dataset
Для анализа используется датасет **Online Retail** из UCI Machine Learning Repository.
Он содержит информацию о транзакциях интернет-магазина за период с декабря 2010 года по декабрь 2011 года.
Основные переменные:
- InvoiceNo - номер транзакции.
- StockCode - код товара.
- Description - название товара.
- Quantity - количество товара.
- InvoiceDate - дата и время транзакции.
- UnitPrice - цена за единицу товара.
- CustomerID - идентификатор покупателя.
- Country - страна покупателя.

### Ожидаемый результат
В результате анализа планируется определить основные тенденции продаж, наиболее востребованные товары, ключевые рынки и особенности покупательского поведения.
На основе полученных результатов будут сформулированы рекомендации по улучшению продаж и работе с клиентами.
