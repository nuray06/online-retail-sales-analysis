# Online Retail: Sales Performance & Customer Behavior Analysis

## Project Overview

В этом проекте я анализирую историю транзакций интернет-магазина, чтобы изучить динамику продаж, популярность товаров и поведение покупателей.
Цель проекта - выявить основные закономерности в данных и сформулировать рекомендации на основе результатов анализа.

## Analysis Questions

1. **Sales Trends:** Как изменяются продажи по месяцам?
2. **Country Analysis:** Какие страны приносят наибольшую сумму продаж?
3. **Product Analysis:** Какие товары наиболее популярны и какие приносят больше всего денег?
4. **Customer Analysis:** Какие покупатели чаще совершают заказы и тратят больше всего?
5. **Returns Analysis:** Как возвраты и отмены влияют на продажи?

## Dataset

Используется датасет **Online Retail** из UCI Machine Learning Repository, содержащий транзакции британского интернет-магазина с декабря 2010 по декабрь 2011 года.
Основные столбцы: `InvoiceNo`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `UnitPrice`, `CustomerID`, `Country`.

## Key Findings

- Наибольшая сумма продаж зафиксирована в ноябре 2011 года - **1,16 млн фунт**.
- Основная часть продаж приходится на Великобританию.
- Самым продаваемым товаром по количеству стал **WORLD WAR 2 GLIDERS ASSTD DESIGNS**.
- Наибольшую сумму продаж среди товаров принёс **REGENCY CAKESTAND 3 TIER**.
- В очищенном датасете обнаружено **4 338 уникальных покупателей**.
- Возвраты и отмены уменьшили сумму продаж на **6,85%**.

## Conclusion

Анализ показал, что количество проданных товаров и их вклад в выручку могут различаться. Также возвраты заметно влияют на итоговую сумму продаж.
На основе результатов можно рекомендовать подробнее изучить причины возвратов, изменения спроса и поведение наиболее активных покупателей.
